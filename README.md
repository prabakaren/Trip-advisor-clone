🌍 Tripadvisor Clone

A front-end recreation of the Tripadvisor homepage, built with pure HTML5 and CSS3 — no JavaScript, no frameworks, no build tools.
Sections Included
Navbar — sticky header with logo, nav links, currency selector, and sign-in button
Hero search — "Where to?" heading with CSS-only tabs (radio + label trick, no JS needed) and a search bar
Promo banner — full-width image with call-to-action
Interest cards — Outdoors, Food, Culture, Water
Inspiration row — 3 cards with save/heart icons
Water activities grid — 4 cards with location tag, star rating, and price
Iconic places — 4 destination cards with an image zoom-on-hover effect
Awards banner — dark promo section with badge overlay
Footer — 4-column link layout, region/currency selectors, and social icons

Built With
HTML5
CSS3 — Flexbox layouts, transitions, hover effects, position: sticky
Font Awesome 6.5.0 for icons
Google Fonts — Inter for typograph
